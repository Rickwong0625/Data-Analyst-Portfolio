# Customer Service KPI Dashboard

## Overview

This project analyzes customer service operational performance using SQL and Power BI.

## Business Problem

Management requires visibility into customer service KPIs to improve operational efficiency and customer satisfaction.

## Tools Used

* MySQL
* Power BI
* Excel

## Key Metrics

* Total Calls
* SLA Compliance
* Customer Satisfaction (CSAT)
* Resolution Rate
* Escalation Volume

## Key Findings

* Service performance remained stable with SLA consistently above target levels.
* Team B demonstrated the strongest operational performance across SLA and CSAT metrics.
* Team C generated the highest escalation volume, indicating potential process improvement opportunities.
* Top-performing agents maintained high productivity without compromising customer satisfaction.

## Recommendations

* Share best practices from high-performing teams.
* Investigate root causes behind elevated escalation rates.
* Implement targeted coaching programs for lower-performing teams.
